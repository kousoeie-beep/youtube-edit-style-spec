# pipeline — 素材1本を1コマンドで動画にする

```bash
uv run --with pillow --with fugashi --with unidic-lite --with mlx-whisper \
  python3 run.py <素材.mov> [--out DIR]
```

**実測: 2分14秒の素材で 12分8秒**（Apple M2）。
同じことを毎回その場で組み立てると **約50分** かかります（2026-08-01 実測）。

## 何をするか

| # | 工程 | 中身 |
|---|---|---|
| ① | プリフライト | 解像度・**回転**・尺・ラウドネス・ffmpegの機能・HWエンコードの可否 |
| ② | 音声抽出＋強調 | `highpass→afftdn→loudnorm→acompressor`（**誤認識の最大レバー**） |
| ③ | ASR 2パス | `mlx-whisper`（Metal）で強調版・生版。**CPU版は7倍遅い** |
| ④ | 多数決照合 | 時刻±0.35秒で語を投票。不一致＋低確信は**字幕から省略** |
| ⑤ | 文節チャンク | 自立語＋付属語で切る。**語境界だけでは字幕が割れる** |
| ⑥ | 字幕PNG | **回転後**のキャンバスで生成。4辺検算つき |
| ⑦ | レンダリング | **loudnorm 2パス** ＋ overlay 1段 ＋ HWエンコード |
| ⑧ | 納品パック | SRT / VTT / transcript.json ＋ QC（LUFS・TruePeak・黒フレーム） |

## 実測値（2026-08-01・iPhone縦撮り 2分14秒）

```
ラウドネス   -29.3 LUFS → **-15.0 LUFS**   （loudnorm 2パス）
True Peak    -2.0 dBFS
黒フレーム    0
4辺検算NG     0件
ASR一致率     **93.9%**（記録の4パス基準91.25%を2パスで超過）
字幕          47件・平均12.4字・語の分断なし
```

## 設計上、意図してこうしてある点

- **キャンバスは回転後の寸法**。`ffprobe` の `width/height` は回転**前**で、
  iPhone縦撮り（`rotation=-90`）をそのまま使うと座標が丸ごとずれる
- **`loudnorm` は必ず2パス**。1パスでは −29 LUFS の素材が −16 までしか上がらない
- **字幕は連番PNG 1本＋overlay 1段**。PNGを38本入力して38段overlayすると
  同じ動画に **19分37秒** かかる（実測・破棄）
- **ASRは `mlx-whisper`**。`openai-whisper` は CPU/FP32 で動き、18分 vs 154秒

## 既知の限界

- **固有名詞の誤認識が残る**（「ワンシート」→「ザマシン」等）。
  `gpt-4o-transcribe` を足すと実測で **+6.75pt** 改善する記録あり
- **笑い声を文字化する**（「ふふふふ…」）。
  仕様が「発音忠実・創作禁止」なので規約どおりだが、実用には除外規則が要る
- **カット（無音除去）未実装**。一次指示書の要件だがこの版には入っていない
- **サムネ5案・タイトル案・説明文 未実装**
