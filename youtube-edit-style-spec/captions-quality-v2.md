# 字幕品質v2（確定手順）

**このファイルは何を扱うか**: 字幕生成の音声強調・複数パスASR照合・改行規則・QCメトリクスの確定手順。
**いつ読むか**: 編集対象に字幕を付ける工程（毎回の編集で発生する主工程）。SKILL.md本体から常に参照される。

## 字幕品質v2（確定手順・2026-07-10実証）

誤認識の最大レバーは**モデルサイズではなく音声強調**。以下を標準とする：

1. **音声強調版を必ず作る**（不明瞭時だけでなく常時）:
   ```bash
   ffmpeg -i audio_16k_mono.wav -af "highpass=f=90,afftdn=nf=-28,loudnorm=I=-14:TP=-1.5,acompressor=threshold=-24dB:ratio=3" audio_enhanced.wav
   ```
2. **ASRは「テキストはAPI・時刻はローカル」に分ける**（2026-07-31 確定。下記 §ASRの振り分け）
3. **複数パス照合（LLM文脈裁定）**: gpt-4o-transcribe / turbo-raw / turbo-enhanced の複数パスを突合し、(a)2パス以上一致→採用 (b)全パス不一致＋低確信(語prob<0.45)→**その語を字幕から省略**し `uncertain_terms.json` に記録 (c)創作・要約・言い回し改善は禁止（発音忠実の原則）。裁定は `caption_corrections.json`（before/after/basis/reason）に必ず記録
4. **改行は語境界のみ**: fugashi（形態素解析）でトークン化し、語の途中で折り返さない（「ギブ経／済圏」分断禁止）。1語が行幅超過する場合のみ語内分割
5. **QCメトリクス**: 低確信語の残存数を qc_selfcheck.md に記録。残存が多い場合は書き出し前に警告
## ASRの実行環境（2026-07-31 実測・M2で7倍差）

**`openai-whisper`（Homebrew版）は CPU / FP32 で動く。Apple Silicon の GPU を一切使わない。**

```
UserWarning: FP16 is not supported on CPU; using FP32 instead
```

同じ音声（2分14秒）・同じモデル（large-v3-turbo）・同じ設定
（`--word_timestamps True --language ja`）での実測:

| 実装 | 所要 | 備考 |
|---|---|---|
| `openai-whisper`（CPU/FP32） | **1080秒（18分）** | M2・8コア・CPU 200% |
| **`mlx-whisper`（Metal）** | **154秒** | **7.0倍速** |

**⇒ ASRは `mlx-whisper` を使う。** 導入は `uv run --with mlx-whisper` だけで済む。

```python
import mlx_whisper
r = mlx_whisper.transcribe(src, path_or_hf_repo="mlx-community/whisper-large-v3-turbo",
                           language="ja", word_timestamps=True)
```

**これは3週間放置されていた既知のボトルネックだった。**
2026-07-10 のパイロットで「処理37.7分・**Whisper 631秒＝80%**」と記録されていたのに、
原因（CPU実行）を特定していなかった。**遅さの正体は実装の選択であってモデルではない。**

複数パス照合が現実的になるのもここが効く。18分×3パスは回せないが、154秒×3なら回せる。

## ASRの振り分け（2026-07-31 確定）

**「APIの方が精度が高いならAPIを使う」は一律には成り立たない。** 中身を見ると1つ明確に劣る。

| 経路 | 実体 | テキスト精度 | 単語タイムスタンプ | 速度 |
|---|---|---|---|---|
| `gpt-4o-transcribe`（API） | 新世代モデル | **最良** | **無い** | 速い |
| ローカル `large-v3-turbo` | Whisper **large-v3** | 良 | **ある**（無料） | 遅い（全処理の80%） |
| `whisper-1`（API） | Whisper **large-v2** | **劣る** | ある | 速い |

**`whisper-1` は large-v2 であり、ローカルの large-v3-turbo より新しくはない。**
だが**単体で置き換えるのではなく、多数決の1パスとして足すと効く**ことが実測で確認されている
（`api-keys.md` run-05）:

> ローカル3パス＋`whisper-1` の**4パス**単語照合で、多数決一致語が
> **338/400 (84.5%) → 365/400 (91.25%)**、要文脈裁定語が **62 → 35** に減少

**単体の精度と、合議に足したときの寄与は別物である。**
「モデルが古いから使わない」と判断すると、この実測を捨てることになる。

### 確定する振り分け

```
テキストの正解  = gpt-4o-transcribe（APIキーがあれば必ず使う。最も精度が高い）
語ごとの時刻    = ローカル large-v3-turbo（--word_timestamps True）
多数決のパス    = ローカル3パス + whisper-1 の4パス（実測で一致率 +6.75pt）
突合            = テキストは gpt-4o-transcribe を正とし、時刻はローカルから供給
キーが無い場合  = ローカル3パスのみで完動する（一致率は 84.5% に落ちる）
```

**なぜこの形か**: 既知の最大欠陥がASRの誤変換だから
（実例「これをすれば」→**「殺すれば」**、「モテたい人」→「思ったい人」）。
これは**テキストモデルの精度で直る**種類の誤りで、時刻精度とは無関係。
逆に時刻はローカルが最良かつ無料なので、わざわざ API に出す理由が無い。

### 落とし穴

- **`gpt-4o-transcribe` に `timestamp_granularities` を渡してはいけない**。
  `whisper-1` 専用のパラメータで、**時刻が要るパスにこのモデルを使うと壊れる**
- **B-roll生成を前提に計画を組まない**。`veo-3.1-fast-generate-preview` は
  当該プロジェクトで HTTP 429（課金・クォータ未有効）。
  **代替の経路は決まっていない**（2026-07-31 時点）。
  ※ 2026-07-14 の「動画生成は Higgsfield」という指定は**別文脈**（Codexレーン・
  　 OpenAI APIキーが無い環境）のもので、**このパイプラインには当てはまらない**。
  　 こちらは OPENAI_API_KEY があり `gpt-image-2` を直接叩いている
- APIのテキストとローカルの語列は**完全一致しない**。突合は
  「APIを正・ローカルは時刻の供給元」と役割を固定し、
  一致しない語は §3 の(b)（低確信→省略）で処理する
- **推測で埋めない**（Gemini の固有名詞推測を却下したのと同じ規則）

- 実例（IMG_2242）: 「義務→ギブ」6箇所・「義バー→ギバー」等が音声強調だけでLLM修正なしに解消。真に不明瞭な音声はどのモデルでも崩れる→省略が正解


## 「語境界で切る」では足りない。必要なのは文節（2026-08-01・実素材で判明）

§4 は「改行は語境界のみ。fugashi でトークン化し語の途中で折り返さない」と定めているが、
**実素材を通したら、これを守っても字幕が分断された。**

```
実装1回目（語境界を遵守）:
  「何をして何を作成したか教えて」/「ほしいですこれはですねワザ」
                        ↑ 教えて|ほしい          ワザ|マシン
```

**原因**: `fugashi`（UniDic）の形態素は言語学的な最小単位であり、
「ワザ」「マシン」「教えて」「ほしい」はそれぞれ独立した形態素として返る。
**形態素境界を守ることと、読める字幕になることは別物。**

### 確定する規則: 文節（自立語＋付属語）で切る

```python
ATTACH = {"助詞", "助動詞", "接尾辞", "補助記号"}     # 直前に吸収する
結合する条件:
  - 付属語（ATTACH）             … 「を」「です」「ました」
  - 名詞 + 名詞                  … ワザ+マシン（複合名詞）
  - 接尾辞 + 名詞                … 1+枚+ペラ（数詞＋助数詞＋名詞）
  - 接頭辞 + 名詞
  - 動詞/助詞 + 動詞             … 教えて+ほしい（補助動詞）
  - 動詞/助詞 + 形容詞
```

さらに**文末（です・ます・ですね・でした 等）で優先的に切る**。
そうしないと「何もしてないです枚ペラを動画」のように2文がまたがる。

実測（2分14秒・314語）: 文節101件 → チャンク38件・**平均11.8字・語の分断ゼロ**。

### なぜ11周の検証で出なかったか

**検証クリップの文言が人工物だったから。**
`"ぱぴぷぺぽバビブベボ"` のような最悪グリフを手で置いていたため、
**形態素解析を一度も通していない**。ASR関連のコードは検証スクリプトに0行だった。

**幾何（重なり・画面外）は人工文字列で測れるが、分割の質は実素材でしか測れない。**
