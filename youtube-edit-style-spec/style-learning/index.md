# スタイル学習（薄いルーター）

**このファイルは何を扱うか**: スタイル学習フロー全体の入口。5段階の手順概要と、各段階の詳細leafへの案内。
**いつ読むか**: こうすけがURL/ファイルを持ち込んで新規スタイルを学習・登録する依頼のとき、または既存スタイルを「〇〇風で」と適用する前に登録状況を確認するとき。現在の工程に必要なleafだけを読み、後工程を先回りして読まない。

## スタイル学習（多ジャンル対応の拡張手順）

参考動画から編集スタイルを抽出し、`../styles/<スタイル名>.yaml` としてプリセット登録する。編集実行時に「〇〇風で」と指定されたら該当プリセットを読み込んで適用する。

**学習手順**（こうすけがURL/ファイルを持ち込んだら実行）:

1. **取得** → 詳細手順（yt-dlp・bot検出回避・切断検知）は [acquisition.md](acquisition.md)
2. **分析** → タイル絵コンテ化・scene検出・ebur128・palettegenの手順は [footage-scan.md](footage-scan.md)
3. **抽出する編集パラメータ** → スキーマ・色ロール規約・登録前ゲート・予約席の規約は [schema.md](schema.md)
4. **登録** → `styles/<名前>.yaml` への保存手順と登録済みスタイル一覧は [registry.md](registry.md)
5. **検証** → テスト適用時の測定原理の落とし穴（オーバーレイ誤検知・無音率下限）は [verification.md](verification.md)

yaml更新後に必ず行う整合性の自己点検（同じ主張を複数箇所で述べている構造の矛盾防止）は [consistency-check.md](consistency-check.md) を参照。
