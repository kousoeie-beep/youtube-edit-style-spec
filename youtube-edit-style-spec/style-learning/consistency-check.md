# スタイル学習: yaml更新後の整合性自己点検

**このファイルは何を扱うか**: yamlを更新したら「同じ主張をしている他のセクション」を全部直すプロセスルールと、その自己点検gr​epコマンド、見落としやすい3パターン。
**いつ読むか**: `styles/*.yaml` を新規作成・更新した直後（本スキルの実行者自身はyamlを編集しないが、他エージェントの更新結果をレビューする際や、将来自分がyamlを触る工程を担当する際の規律として参照）。

**【最重要・プロセスルール】yamlを更新したら「同じ主張をしている他のセクション」を必ず全部直す**（2026-07-25〜26に同種のミスが3回発生した）:
yamlは source / confidence / format / palette / telop_layers / variant_split / apply_notes / dual_mode と**同じ事実を複数箇所で述べる構造**になっている。1箇所だけ直すと**同一ファイル内で矛盾する**。実際に起きた事例:
- `wipe_explainer`: n増で「赤コールアウトは使う」と本文を訂正したが `telop_layers` にroleを追加し忘れた
- `documentary_cinematic`: A1/A2のタイルを目視して3変種と確定させたのに、`confidence`・`source`・`camera`・`broll_usage`・`background_hex`・`dual_mode` の**6箇所に「A1/A2は未確認」が残った**
- 同ファイル: telop_layersにA2のroleを追加したのに `source` は「A2は反映していない」のままだった

**更新後に必ず実行する自己点検**:
```bash
grep -nE "未確認|未検証|未計測|類推|n=1|のみ|無いため|しか実測|反映していない|タイル未生成" <style>.yaml
```
ヒットした各行について「この記述は今も真実か？」を確認する。実測で覆ったものは**その場で訂正するか、訂正済みである旨を明記する**。

**特に見落としやすい3パターン**（実際に検出漏れした）:
- **`hook` フィールド**が横断的に古くなる。3ファイル全てで「該当チャンネルのhookタイルが無い/未確認」が、sourceの「タイル生成・目視済み」と矛盾していた。**タイルを追加生成したら `hook` / `camera` / `broll_usage` / `background_hex` を必ず見直す**（これらは変種ごとに書き分ける必要があるフィールド）
- **「〜のみ」表現**（例「目視実測=A3のみ」「視覚文法はA3のみの実測」）。「未確認」という語を含まないため素朴なgrepでは引っかからないが、実質同じ主張
- **apply_notes冒頭の「最大の限界」ブロック**。検証課題リスト（末尾）は直しても、冒頭の総括を直し忘れる

**根本原因**: 「実測して分かったこと」を書き足すのは覚えているが、**「もう真実でなくなった記述を消す」のを忘れる**。追記より削除の方が忘れやすい。

## 機械照合を先に流す（2026-07-27 追加）

```bash
uv run --with pyyaml --offline python3 styles/lint.py
```

`styles/lint.py` は**2026-07-27に実害を出した6つの型**を機械で見る。
終了コード 0=クリーン / 1=違反あり なので `lint && レンダリング` と繋げる。

| 検査 | なぜ必要か（実害） |
|---|---|
| YAMLとして読めるか | `style` の値が改行＋コメントで**切断**されていた |
| 重複キー | 先に書いた値が黙って消える。**同じ事故を3度作った**（`max_chars: 10` が旧`20`に、`max_width_px: 624` が旧`未計測`に、`color_bg` が上書きで消滅） |
| 排他の非対称 | 片側だけの宣言は、もう一方だけ読んだ実装者に伝わらない。1件は**CTAの価格+URL帯を58.5%潰した**組み合わせだった |
| max_lines の欠落 | 幅だけ縛ると**行数が増えて悪化する**。5スタイルで再現（3行31px→4行86px侵入 等） |
| 1行設計なのに max_lines≧2 | `max_lines` が安全上限でなく**破綻の許可証**になる。検証で「可」だったスタイルを1本退行させた |
| opaque_fullscreen に size 無し | 宣言だけでは1ピクセルも覆えない。実測の被覆率は14.4%〜31.4% |

**人力の目視チェックリストより先に、これを流すこと。**
規約に書いただけでは守られないことが同日に何度も証明されている
（規約を定めた直後に自分で5件違反した回もある）。
